# SAMZLAB site (GitHub Pages)
1. github.com/SAMZLAB-PK → New repository → name exactly **SAMZLAB.github.io** → Public → Create.
2. Upload everything in this folder (index.html, privacy.html, rimota-icon.png, .nojekyll) → Commit.
3. Repo Settings → Pages → Source: "Deploy from a branch" → main / root → Save.
4. In 1-2 minutes: https://samzlab.github.io/ and https://samzlab.github.io/privacy.html  ← Play Console "Privacy policy" URL.
Replace `samzlabpk@gmail.com` in index.html and privacy.html with your email (find & replace).
