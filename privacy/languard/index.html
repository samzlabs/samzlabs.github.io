LanGuard Pro Privacy Policy

Last updated: August 8, 2026

LanGuard Pro is a network and router management application developed by SAMZLAB for compatible OpenWrt and ImmortalWrt routers.

LanGuard Pro is designed primarily as a local-first application. Router and connected-device information is processed to provide network-management features requested by the user.

Information Processed by LanGuard Pro

When the user connects LanGuard Pro to a compatible router, the app may access and process technical information available from that router, including:

  • Router IP address and connection information
  • Connected-device names
  • Device IP addresses
  • Device MAC addresses
  • Online and offline device status
  • Network usage and traffic statistics
  • Device access-control status
  • Speed-limit and priority settings
  • Reserved IP or device configuration
  • AdBlock and supported router-service status

Router Credentials

Users may provide router connection credentials so that LanGuard Pro can communicate with and manage their own router.

Router credentials are used only for the router-management functionality requested by the user. Users are responsible for protecting access to their Android device, router, and router administration credentials.

How Information Is Used

LanGuard Pro uses router and network information to provide features such as displaying connected devices, monitoring network activity, changing device settings, blocking or allowing devices, configuring speed limits and priorities, and managing supported router services.

Local-First Operation

LanGuard Pro is primarily designed to communicate between the Android device and the router configured by the user.

SAMZLAB does not operate a LanGuard Pro cloud service that collects or stores users' router device lists, MAC-address databases, or local network-usage databases.

Data Sharing and Sale

LanGuard Pro does not sell users' personal information.

Router-management information is not shared by SAMZLAB with advertisers for advertising or marketing purposes.

Data Storage

Some application settings and router-management information may be stored locally on the user's Android device or on the user's router where necessary to provide LanGuard Pro functionality.

Data Retention and Deletion

Users can remove locally stored Android application data by clearing LanGuard Pro's app data or uninstalling the application.

Router-side LanGuard Pro information can be removed using the available LanGuard Pro router uninstall, reset, or removal functionality.

Because SAMZLAB does not maintain a LanGuard Pro user-account database or cloud device database, there is normally no LanGuard Pro cloud account or associated cloud network database for SAMZLAB to delete.

Network and Internet Access

LanGuard Pro requires network access to communicate with routers configured by the user and to perform supported network-management functions.

The Android operating system, router firmware, internet service provider, or other network infrastructure may independently process technical connection information under their own policies.

Security

LanGuard Pro is designed to limit router-management information to the functionality required by the application. Users should use strong router passwords, keep router firmware updated, and restrict router administrative access to trusted devices and networks.

Children's Privacy

LanGuard Pro is a technical network-administration utility and is not designed or directed specifically toward children.

Third-Party Services

If future versions of LanGuard Pro introduce third-party services or SDKs that change how user data is collected, transmitted, or shared, this Privacy Policy and the Google Play Data Safety declaration will be updated accordingly.

Changes to This Privacy Policy

This Privacy Policy may be updated when LanGuard Pro features, legal requirements, or data practices change. The latest version will always be published on this page.
